# EasyStudy
Game-style study site for a Primary 1 student. Static site (HTML/CSS/JS + JSON + mp3), served from `public/` with Cloudflare Workers assets (`npx wrangler deploy`).
Update lessons: run `./sync.sh` (copies from the project folder, commits, pushes).

Shared database and one dashboard since 2026-11-21 (APP_ID study|words).
